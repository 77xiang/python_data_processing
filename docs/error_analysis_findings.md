## 主要发现

1. **三个模型都存在系统性偏差，方向与区域负荷漂移一致。**
   测试期（11–12 月）Z1、Z3 的负荷均值较训练期明显下移（B3 日志：Z1 33,065→29,056，Z3 20,052→11,949），导致依赖训练期水平的 LR 和 GBT 在 Z1/Z3 持续**高估**（GBT bias：Z1 +1020、Z3 +1670）；Z2 漂移方向相反，模型转为**低估**（GBT bias −532）。历史同期基线 bias 最小（−17 ~ +108），因为它锚定上周同期值，不依赖训练期水平。

2. **高峰时段绝对误差显著更大，且方向转为低估。**
   GBT 在 Z2 高峰时段（≥训练集 Q90 = 27,221）RMSE 2761，是普通时段（1125）的 2.5 倍，bias 由 −271 变为 −1330——模型在高峰时段压不住峰值。Z1 测试期高峰样本仅 9 条、Z3 为 0 条（测试期负荷整体下移，极少超过训练期 Q90），这两个区域的高峰结论样本不足，只能作参考。

3. **区域间公平比较要用相对指标。**
   按 nRMSE（RMSE/区域均值）：基线 3.96%/5.81%/18.55%，GBT 7.72%/7.15%/19.98%。Z3 对所有模型都最难（nRMSE 13.9%–20.0%），不是模型在 Z3 上"更差"，而是 Z3 测试期相对波动最大。

4. **残差结构**：见 fig8_residual_dist / fig8_residual_time。GBT 残差在 Z1/Z3 整体右偏（对应高估），日平均残差随时间有漂移趋势，提示负荷水平的非平稳性是主要误差来源。

## 现有数据不能确认的推断

- Z1/Z3 高峰时段模型表现（样本太少，9 条 / 0 条）；
- 负荷下移的原因（数据只有一年、单地区，无法区分季节性与趋势性）；
- "模型差"与"任务难"的边界——Z3 的高 nRMSE 是数据特性还是模型缺陷，一年数据下无法分离。
